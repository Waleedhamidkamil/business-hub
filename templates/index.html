App settings

Document Records

Browse, relink, and delete every saved document.

Appearance

Choose a light or dark theme for the app. Document PDFs are always printed light.

Logo

One logo image is used for the header of every document type.

PNG or JPEG. Applies to every document's header on the next preview or save.

Save paths

Where every document type is filed on disk.

Root for every doc type. The tree looks like:
<base>\QUOTATIONS\<Client>\<Year>\<Month>\
<base>\INVOICES\<Client>\<Year>\<Month>\
<base>\DELIVERY NOTES\<Client>\<Year>\<Month>\
<base>\PURCHASE ORDERS\<Year>\<Month>\
Override only if you want POs filed somewhere different from the base path. Leave empty for the default.

App language

Language of the app chrome (buttons, menus, modals). Document text inside PDFs is unaffected - those use whatever you typed.

The Purchase Order section keeps its Arabic labels either way (it's an Arabic document).

After exporting a PDF

What should happen the moment a document is exported with the Export button.

Copying lets you paste the file straight into WhatsApp, Outlook or a folder. The document is always saved either way.

Editor preferences

Small conveniences applied across the document editors.

Digital Signatures & Stamp

Upload up to 3 signatures and 1 stamp. The Sign button in every editor lets you drop them onto the document above the signature line, with a small natural-looking randomization each time.

Sign automatically when saving

Every document you save is signed and stamped for you, with the same natural-looking randomization. Delivery Notes sign the Supplier box only - the Recipient box stays blank for the client to sign by hand.

A document you signed by hand keeps that choice - saving only re-rolls the position. Turn this off if you want to sign documents manually.

Document Header, Closing & Addresses

The company header lines, title, brand color, closing line, and client-address dropdown options - edited per document type.

Saves to the selected document type only. Signature labels stay in each type's own settings.

Payment accounts

The accounts money arrives in. Each one carries its own exchange rate, and that rate is what a document's COSTS are converted at when the client is paid into it. It does not change what an invoice bills.

When no account is known

Used for a client with no receiving account set in Master Data.
